Architecture Microservices

Du monolithe aux microservices — Durée : 4h · Instructeur : Olivier Planson

Microservices API Gateway Circuit Breaker Docker Compose Saga Service Discovery

Objectifs pédagogiques

✅Comprendre les principes d'architecture microservices
✅Décomposer des applications monolithiques en services
✅Implémenter la communication inter-services
✅Appliquer le pattern API Gateway
✅Configurer la découverte de services et la configuration externalisée
✅Implémenter le tracing distribué et le monitoring
✅Gérer la cohérence des données en systèmes distribués
✅Déployer des microservices avec Docker Compose

Plan du cours

  1. Qu'est-ce que les microservices — définition et comparaison
  2. Bénéfices et défis des microservices
  3. Stratégies de décomposition — Domain decomposition
  4. Communication inter-services — REST et asynchrone
  5. Pattern API Gateway
  6. Découverte de services et configuration
  7. Observabilité — tracing, logging, métriques
  8. Cohérence des données — Saga, CQRS, Event Sourcing
  9. Déploiement avec Docker Compose
  10. Patterns de déploiement et CI/CD

☰ Contenu du cours

Monolithe vs microservices, décomposition DDD, communication inter-services, API Gateway, observabilité, Saga, Docker Compose avec diagrammes.

◈ Concepts clés

Comparatifs, stratégies de communication, patterns microservices, piliers de l'observabilité, théorème CAP et glossaire.

⟨/⟩ Exemples de code

Fault Tolerance, API Gateway, MicroProfile Config, Health Check, Saga choreography, Docker Compose, corrélation ID.

⧫ Patterns Microservices

API Gateway, Circuit Breaker, Database per Service, Saga, CQRS et Event Sourcing — avec diagrammes SVG.
