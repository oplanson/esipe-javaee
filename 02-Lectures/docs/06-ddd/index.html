Domain-Driven Design

Patterns stratégiques et tactiques pour applications enterprise — Durée : 3h · Instructeur : Olivier Planson

DDD Bounded Context Aggregates Domain Events Value Objects Repositories

Objectifs pédagogiques

✅Comprendre la philosophie DDD et ses bénéfices
✅Appliquer les patterns stratégiques (Bounded Contexts, Context Maps)
✅Implémenter les patterns tactiques (Entités, Value Objects, Aggregats)
✅Concevoir des modèles de domaine avec le langage ubiquitaire
✅Refactoriser du code existant vers l'architecture DDD
✅Appliquer DDD à l'application bancaire

Plan du cours

  1. Introduction DDD — philosophie et bénéfices
  2. Patterns Stratégiques — Bounded Contexts
  3. Langage Ubiquitaire
  4. Patterns Tactiques — Entité
  5. Patterns Tactiques — Value Object
  6. Patterns Tactiques — Aggregate
  7. Repository pattern
  8. Domain Services et Events
  9. Refactorisation vers DDD — Application bancaire

☰ Contenu du cours

Philosophie DDD, Bounded Contexts, Entités, Value Objects, Aggregats, Domain Events et architecture en couches.

◈ Concepts clés

DDD stratégique vs tactique, Entité vs Value Object, règles des Aggregates, architecture en couches, glossaire.

⟨/⟩ Exemples de code

Account, Money, AccountNumber, Aggregate complet, Repository JPA, TransferService, Domain Events CDI, Records Java 17.
