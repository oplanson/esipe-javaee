Domain-Driven Design

Strategic and tactical patterns for enterprise applications — Duration: 3h · Instructor: Olivier Planson

DDD Bounded Context Aggregates Domain Events Value Objects Repositories

Learning Objectives

✅Understand the DDD philosophy and its benefits
✅Apply strategic patterns (Bounded Contexts, Context Maps)
✅Implement tactical patterns (Entities, Value Objects, Aggregates)
✅Design domain models with the ubiquitous language
✅Refactor existing code towards DDD architecture
✅Apply DDD to the banking application

Course Outline

  1. Introduction to DDD — philosophy and benefits
  2. Strategic Patterns — Bounded Contexts
  3. Ubiquitous Language
  4. Tactical Patterns — Entity
  5. Tactical Patterns — Value Object
  6. Tactical Patterns — Aggregate
  7. Repository pattern
  8. Domain Services and Events
  9. Refactoring towards DDD — Banking application

☰ Course Content

DDD philosophy, Bounded Contexts, Entities, Value Objects, Aggregates, Domain Events and layered architecture.

◈ Key Concepts

Strategic vs tactical DDD, Entity vs Value Object, Aggregate rules, layered architecture, glossary.

⟨/⟩ Code Examples

Account, Money, AccountNumber, complete Aggregate, JPA Repository, TransferService, CDI Domain Events, Java 17 Records.
