Concepts clés

Comparatifs, tableaux de référence et glossaire pour CDI et la gestion des transactions.

CDI vs EJB

FonctionnalitéCDI BeanEJB (Session Bean)
Gestion des transactionsVia @Transactional (CDI Interceptor)Nativement intégrée (CMT)
Sécurité déclarativeVia intercepteur personnalisé@RolesAllowed, @DenyAll intégrés
Clustering & passivation❌ Non supporté nativement✅ Stateful beans passivables
Accès distant (Remote)❌ Non✅ Via @Remote
Complexité✅ Légère, POJO⚠️ Plus lourde, spécification dédiée
Usage recommandéServices applicatifs modernes, microservicesApplications legacy, transactions distribuées

Scopes CDI comparés

ScopeAnnotationDurée de vieCas d'usage typique
Application@ApplicationScopedDurée de vie de l'applicationServices stateless, caches, configuration
Session@SessionScopedDurée de la session HTTP utilisateurPanier, préférences, état de connexion
Request@RequestScopedDurée d'une requête HTTPTraitement de formulaire, opérations unitaires
Conversation@ConversationScopedConversation explicitement géréeWizards multi-étapes, formulaires longs
Dependent@Dependent (défaut)Liée au bean injecteurValue objects, helpers, beans légers
Singleton@Singleton (Jakarta Concurrency)Durée de vie de l'application (thread-safe)Ressources partagées avec accès concurrent

CMT vs BMT

AspectCMT — Container-Managed TransactionsBMT — Bean-Managed Transactions
GestionDéléguée au conteneur via @TransactionalManuelle via UserTransaction
Code transactionnelAbsent du code métier (déclaratif)Présent dans le code (begin/commit/rollback)
Complexité✅ Faible — annotations uniquement⚠️ Élevée — gestion explicite des erreurs
FlexibilitéLimitée aux types de propagation standard✅ Totale — logique transactionnelle sur mesure
Recommandé pourLa grande majorité des cas d'usageCas avancés : saga, transactions longues
RollbackAutomatique sur RuntimeExceptionExplicite : tx.rollback() dans le catch

Glossaire

TermeDéfinition
CDIContexts and Dependency Injection — spécification Jakarta EE pour l'injection de dépendances et la gestion du cycle de vie des beans
@InjectAnnotation standard (Jakarta Inject) demandant au conteneur CDI d'injecter une dépendance dans un champ, constructeur ou méthode
@QualifierMéta-annotation permettant de créer des qualificateurs personnalisés pour lever l'ambiguïté lors de l'injection de plusieurs implémentations
@ProducesAnnotation déclarant une méthode ou un champ comme source d'un bean CDI — utile pour les objets nécessitant une logique de création complexe
@InterceptorAnnotation marquant une classe comme intercepteur CDI — s'intercale dans l'invocation des méthodes pour ajouter un comportement transversal
@DecoratorAnnotation marquant un bean comme décorateur — enveloppe un bean existant pour enrichir son comportement, contrairement aux intercepteurs qui sont agnostiques du type
@ObservesAnnotation placée sur un paramètre de méthode pour s'abonner à un type d'événement CDI — la méthode est appelée automatiquement lors du déclenchement
UserTransactionInterface Jakarta Transactions permettant la gestion programmatique (BMT) des transactions — begin(), commit(), rollback(), setRollbackOnly()
