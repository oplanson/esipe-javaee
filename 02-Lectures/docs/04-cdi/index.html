CDI — Injection de Dépendances

Jakarta Contexts and Dependency Injection — Durée : 3h · Instructeur : Olivier Planson

CDI 4.0 @Inject Scopes Interceptors Events @Transactional

Objectifs pédagogiques

✅Comprendre les principes et bénéfices de l'injection de dépendances
✅Utiliser les annotations CDI pour gérer le cycle de vie des beans
✅Appliquer les différents scopes de beans
✅Implémenter les qualificateurs pour l'injection type-safe
✅Utiliser les Producer Methods pour la création d'objets complexes
✅Appliquer la gestion déclarative des transactions avec @Transactional

Plan du cours

  1. Qu'est-ce que l'Injection de Dépendances — problème du new, solution CDI
  2. Scopes CDI — @ApplicationScoped, @RequestScoped, @SessionScoped, @Dependent
  3. Injection avec @Inject — field, constructor, method injection
  4. Qualificateurs CDI — @Qualifier, résolution d'ambiguïté, @Alternative
  5. Producer Methods — @Produces, @Disposer, configuration
  6. Intercepteurs — @InterceptorBinding, @AroundInvoke, logging, sécurité
  7. Transactions @Transactional — REQUIRED, REQUIRES_NEW, rollback strategies
  8. CDI Events — @Observes, Event<T>, événements synchrones et asynchrones

☰ Contenu du cours

Scopes, @Inject, Qualificateurs, Intercepteurs, Transactions et Events avec diagrammes.

◈ Concepts clés

CDI vs EJB, comparatif des scopes, types de transactions, CMT vs BMT, glossaire.

⟨/⟩ Exemples de code

Services @ApplicationScoped, qualificateurs, producers, intercepteurs, @Transactional, events.
