Architecture Hexagonale

Ports & Adapters pour des applications propres et testables — Durée : 2h · Instructeur : Olivier Planson

Hexagonal Ports Adapters Clean Arch DIP Tests

Objectifs pédagogiques

✅Comprendre les principes de l'architecture hexagonale et ses bénéfices
✅Appliquer le pattern Ports and Adapters
✅Implémenter le Principe d'Inversion de Dépendances (DIP)
✅Concevoir une architecture propre avec séparation des couches
✅Créer des applications testables avec des adapters mock
✅Refactoriser du code DDD vers l'architecture hexagonale

Plan du cours

  1. Introduction et évolution des architectures
  2. Principe d'Inversion de Dépendances (DIP)
  3. Structure hexagonale — Domaine, Ports, Adapters
  4. Ports primaires vs secondaires
  5. Package structure et dependency flow
  6. Implémentation des ports et adapters
  7. Stratégies de test avec l'hexagonale
  8. Refactorisation depuis DDD vers hexagonale
