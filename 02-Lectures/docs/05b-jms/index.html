JMS — Messagerie Enterprise

Jakarta Messaging Service — Durée : 2h · Instructeur : Olivier Planson

JMS 3.0 @MessageDriven Queue Topic Pub/Sub Dead Letter Queue

Objectifs pédagogiques

✅Comprendre la messagerie enterprise et les bénéfices
✅Utiliser les modèles Point-à-Point (Queue) et Pub/Sub (Topic)
✅Implémenter des Message-Driven Beans
✅Gérer les transactions avec JMS
✅Traiter les messages défaillants avec Dead Letter Queue
✅Optimiser les performances JMS

Plan du cours

  1. Concepts de messagerie enterprise
  2. Architecture JMS et composants
  3. Point-à-Point avec Queue
  4. Pub/Sub avec Topic
  5. Types de messages JMS
  6. Producteurs et consommateurs de messages
  7. Message-Driven Beans (MDB)
  8. Transactions JMS
  9. Dead Letter Queue et gestion des erreurs

☰ Contenu du cours

Architecture JMS, Queue, Topic, MDB, transactions et gestion des erreurs avec diagrammes.

◈ Concepts clés

Messagerie vs appels directs, Queue vs Topic, types de messages, API JMS 2.0, glossaire.

⟨/⟩ Exemples de code

Producteur JMSContext, consommateur async, MDB Queue/Topic, Dead Letter Queue, sélecteurs, Liberty.
