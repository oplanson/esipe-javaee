JSF — JavaServer Faces

Component-oriented UI framework — Duration: 3h · Instructor: Olivier Planson

JSF Facelets CDI EL Validators Navigation

Learning Objectives

✅Understand the JSF architecture and the 6-phase lifecycle
✅Create CDI managed beans for JSF
✅Use Facelets for page templates
✅Implement validation and conversion
✅Use AJAX with JSF
✅Manage navigation between views

Course Plan

  1. JSF architecture and lifecycle (6 phases)
  2. Managed Beans with CDI (scopes)
  3. Facelets and templates
  4. JSF Core components (input, output, command)
  5. Validation and Converters
  6. AJAX with f:ajax
  7. Navigation Rules
  8. JSF best practices
