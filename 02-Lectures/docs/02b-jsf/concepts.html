Scopes des Beans CDI dans JSF

AnnotationDurée de vieUsage typique
@RequestScopedDurée d'une requête HTTPActions ponctuelles, formulaires simples
@ViewScopedDurée d'une vue JSFFormulaires avec AJAX, édition en place
@SessionScopedDurée d'une session HTTPUtilisateur connecté, panier, préférences
@ApplicationScopedDurée de l'applicationCaches globaux, données de référence
@DependentDépend du bean parentBeans utilitaires sans état propre

Phases du Cycle de Vie JSF

#PhaseDescriptionCe qui se passe
1Restore ViewRestauration ou création de la vueReconstruction de l'arbre UIComponent depuis le ViewState ou création d'un nouvel arbre
2Apply Request ValuesApplication des valeurs de la requêteChaque composant lit sa valeur depuis les paramètres HTTP et la stocke localement
3Process ValidationsExécution des validationsValidateurs et convertisseurs s'exécutent ; les erreurs sont ajoutées au FacesContext
4Update Model ValuesMise à jour du modèleLes valeurs validées sont poussées vers les propriétés des beans via les ValueExpressions
5Invoke ApplicationInvocation de l'applicationLes méthodes d'action et action listeners sont exécutés ; l'outcome détermine la navigation
6Render ResponseRendu de la réponseL'arbre de composants est encodé en HTML et envoyé au client ; le ViewState est sauvegardé

Glossaire

TermeDéfinition
JSFJavaServer Faces — framework MVC orienté composants pour la construction d'interfaces web Jakarta EE ; spécification Jakarta Faces depuis EE 9
FaceletsMoteur de templating officiel de JSF depuis JSF 2.0 remplaçant JSP ; les fichiers ont l'extension .xhtml et respectent la syntaxe XML
Managed BeanBean CDI annoté @Named servant de contrôleur dans JSF ; expose ses propriétés et méthodes à l'Expression Language des vues Facelets
ELExpression Language — syntaxe #{...} permettant d'accéder aux beans et leurs propriétés depuis les vues JSF ; supporte navigation de propriétés et appels de méthodes
faces-config.xmlFichier de configuration XML de JSF dans /WEB-INF/ permettant de déclarer des règles de navigation explicites, des convertisseurs, validateurs et managed beans (déprécié pour ces derniers)
UIComponentClasse de base de tous les composants JSF formant l'arbre de composants (Component Tree) — chaque balise JSF comme h:inputText crée une instance UIComponent
ValueExpressionExpression EL de type #{bean.property} permettant de lire et d'écrire (binding bidirectionnel) une valeur entre un composant JSF et un bean CDI
ActionEventÉvénement déclenché par un composant d'action (h:commandButton, h:commandLink) ; traité par les ActionListeners ou les méthodes d'action retournant un outcome de navigation
