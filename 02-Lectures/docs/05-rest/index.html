JAX-RS — Services RESTful

Jakarta RESTful Web Services — Durée : 3h · Instructeur : Olivier Planson

JAX-RS 3.1 JSON-B OpenAPI Fault Tolerance Rest Client CDI Integration

Objectifs pédagogiques

✅Comprendre les principes REST
✅Créer des ressources RESTful avec JAX-RS
✅Gérer JSON avec JSON-B
✅Implémenter la gestion des exceptions et validation
✅Utiliser MicroProfile Rest Client
✅Intégrer REST avec CDI

Plan du cours

  1. Principes REST et modèle de maturité Richardson
  2. Annotations JAX-RS (@Path @GET @POST @PUT @DELETE)
  3. JSON-B et sérialisation
  4. Gestion des exceptions et validation
  5. MicroProfile Rest Client (type-safe)
  6. Intégration REST + CDI
  7. OpenAPI et documentation
  8. Tests REST

☰ Contenu du cours

Richardson Maturity Model, annotations JAX-RS, JSON-B, exceptions, Rest Client, CDI, OpenAPI avec diagrammes.

◈ Concepts clés

REST vs SOAP, modèle Richardson, annotations clés, codes HTTP, comparaison des clients, glossaire.

⟨/⟩ Exemples de code

Ressource JAX-RS complète, JSON-B, ExceptionMapper, Bean Validation, MicroProfile Rest Client, Circuit Breaker.
