Jakarta REST — RESTful Web Services

Jakarta RESTful Web Services (formerly JAX-RS) — Duration: 3h · Instructor: Olivier Planson

Jakarta REST 3.1 JSON-B OpenAPI Fault Tolerance Rest Client CDI Integration

Learning Objectives

✅Understand REST principles
✅Create RESTful resources with Jakarta REST
✅Handle JSON with JSON-B
✅Implement exception handling and validation
✅Use MicroProfile Rest Client (type-safe)
✅Integrate REST with CDI

Course Outline

  1. REST principles and Richardson Maturity Model
  2. Jakarta REST annotations (@Path @GET @POST @PUT @DELETE)
  3. JSON-B and serialization
  4. Exception handling and validation
  5. MicroProfile Rest Client (type-safe)
  6. REST + CDI integration
  7. OpenAPI and documentation
  8. REST testing

☰ Course Content

Richardson Maturity Model, Jakarta REST annotations, JSON-B, exceptions, Rest Client, CDI, OpenAPI with diagrams.

◈ Key Concepts

REST vs SOAP, Richardson model, key annotations, HTTP codes, client comparison, glossary.

⟨/⟩ Code Examples

Complete Jakarta REST resource, JSON-B, ExceptionMapper, Bean Validation, MicroProfile Rest Client, Circuit Breaker.
