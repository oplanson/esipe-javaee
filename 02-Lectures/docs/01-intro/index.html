Introduction to Jakarta EE and MicroProfile

Enterprise Java Development with Open Liberty — Duration: 2h · Instructor: Olivier Planson

Jakarta EE 10 MicroProfile 6 Open Liberty Java 17 Podman Maven

Learning Objectives

✅Understand the Jakarta EE and MicroProfile ecosystems
✅Differentiate Jakarta EE and MicroProfile
✅Identify key specifications and APIs
✅Set up the Open Liberty development environment
✅Create and deploy a first application with Podman
✅Understand the role of application servers

Course Outline

  1. Introduction to Jakarta EE — history, J2EE → Jakarta EE
  2. Introduction to MicroProfile — cloud-native, specifications
  3. Jakarta EE vs MicroProfile — comparison and complementarity
  4. Jakarta EE Specifications — Web, Business, Persistence
  5. MicroProfile Config, Health, Metrics — examples
  6. Open Liberty — lightweight and modular runtime
  7. Jakarta EE + MicroProfile project structure
  8. Environment setup (JDK 17, Maven, Podman)
  9. First servlet with Health Check
  10. Open Liberty server.xml configuration
  11. Build with Liberty Maven Plugin
  12. Containerisation with Podman (Containerfile)
  13. Banking application architecture
  14. Course roadmap
