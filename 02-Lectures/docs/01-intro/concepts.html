Glossaire

TermeDéfinition
Jakarta EEAnciennement Java EE — plateforme de spécifications pour applications enterprise Java, gérée par l'Eclipse Foundation depuis 2017
MicroProfileEnsemble de spécifications complémentaires à Jakarta EE, ciblant les architectures microservices et cloud-native
Open LibertyServeur d'applications open-source d'IBM, implémentant Jakarta EE 10 et MicroProfile 6, optimisé pour les conteneurs
PodmanOutil de gestion de conteneurs OCI sans daemon, compatible avec la CLI Docker, permettant l'exécution rootless
WARWeb Application Archive — format de packaging Java pour les applications web déployées sur un serveur d'applications
CDIContexts and Dependency Injection — mécanisme d'injection de dépendances standardisé de Jakarta EE
JPAJakarta Persistence API — spécification pour le mapping objet-relationnel (ORM) en Java
JAX-RSJakarta RESTful Web Services — API pour la création de services REST avec des annotations Java
