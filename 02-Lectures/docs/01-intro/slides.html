🎯 Qu'est-ce que Jakarta EE ?

Jakarta EE (anciennement Java EE) est un ensemble de spécifications pour la construction d'applications d'entreprise en Java.

Caractéristiques clés :

  • Basé sur des standards : Spécifications industrielles
  • Indépendant des fournisseurs : Plusieurs implémentations disponibles
  • Enterprise-ready : Conçu pour la scalabilité et la fiabilité
  • Open-source : Développement communautaire sous Eclipse Foundation

🚀 Qu'est-ce que MicroProfile ?

Eclipse MicroProfile est un ensemble de spécifications optimisées pour l'architecture microservices.

Caractéristiques clés :

  • Cloud-native : Conçu pour le cloud et les conteneurs
  • Orienté microservices : Léger et modulaire
  • Complémentaire à Jakarta EE : Étend les capacités Jakarta EE
  • Innovation rapide : Cycles de release plus courts que Jakarta EE

📦 Spécifications Jakarta EE

Technologies Web

  • Jakarta Servlet — Gestion des requêtes/réponses HTTP
  • Jakarta Server Pages (JSP) — Pages web dynamiques
  • Jakarta Server Faces (JSF) — Framework UI orienté composants

Logique métier

  • Jakarta CDI — Injection de dépendances
  • Jakarta EJB — Composants métier

Persistance des données

  • Jakarta JPA — Mapping objet-relationnel
  • Jakarta JTA — Gestion des transactions
⚡ Spécifications MicroProfile

Configuration

  • MP Config — Configuration externalisée, mise à jour dynamique

Observabilité

  • MP Health — Endpoints de santé
  • MP Metrics — Métriques de l'application
  • MP OpenTracing — Tracing distribué

Résilience

  • MP Fault Tolerance — Circuit breakers, retries, timeouts
  • MP Rest Client — Clients REST type-safe
