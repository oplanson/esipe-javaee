Jakarta EE Security

Authentication, authorization and security best practices — Duration: 3h · Instructor: Olivier Planson

Security JWT OAuth2 HTTPS/TLS RBAC OWASP

Learning Objectives

✅Understand security fundamentals (authentication, authorization, encryption)
✅Implement Jakarta Security API in enterprise applications
✅Apply declarative and programmatic security
✅Secure REST APIs with JWT tokens
✅Integrate OAuth2 and OpenID Connect
✅Follow security best practices
✅Secure microservices architectures

Course Outline

  1. Security Principles — CIA Triad, OWASP Top 10 threats
  2. Authentication vs Authorization
  3. Authentication Methods (Basic, Form, Token, Certificate)
  4. Authorization Models (RBAC, ABAC)
  5. Jakarta Security API
  6. JWT with MicroProfile JWT
  7. HTTPS/TLS — configuration
  8. REST API Security
  9. Microservices Security
