Jakarta EE Security

Authentification, autorisation et bonnes pratiques de sécurité — Durée : 3h · Instructeur : Olivier Planson

Security JWT OAuth2 HTTPS/TLS RBAC OWASP

Objectifs pédagogiques

✅Comprendre les fondamentaux de sécurité (authentication, authorization, chiffrement)
✅Implémenter Jakarta Security API dans des applications enterprise
✅Appliquer la sécurité déclarative et programmatique
✅Sécuriser les APIs REST avec les tokens JWT
✅Intégrer OAuth2 et OpenID Connect
✅Suivre les bonnes pratiques de sécurité
✅Sécuriser les architectures microservices

Plan du cours

  1. Principes de sécurité — CIA Triad, menaces OWASP Top 10
  2. Authentification vs Autorisation
  3. Méthodes d'authentification (Basic, Form, Token, Certificate)
  4. Modèles d'autorisation (RBAC, ABAC)
  5. Jakarta Security API
  6. JWT avec MicroProfile JWT
  7. HTTPS/TLS — configuration
  8. Sécurité des APIs REST
  9. Sécurité des microservices
