JPA & Intégration Base de données

Jakarta Persistence API — Durée : 4h · Instructeur : Olivier Planson

JPA 3.1 JPQL PostgreSQL JTA EntityManager Migrations

Objectifs pédagogiques

✅Comprendre le mapping Objet-Relationnel (ORM)
✅Créer et configurer des entités JPA
✅Définir les relations entre entités (1-1, 1-N, N-N)
✅Écrire des requêtes JPQL et Criteria API
✅Gérer les transactions efficacement
✅Gérer les migrations de base de données
✅Utiliser JNDI pour les ressources

Plan du cours

  1. ORM et architecture JPA
  2. Annotations de base (@Entity, @Table, @Id)
  3. Relations entre entités
  4. JPQL — requêtes orientées objets
  5. Criteria API — requêtes dynamiques
  6. Gestion des transactions (CMT et BMT)
  7. Migrations avec Flyway
  8. Configuration JNDI et DataSource

☰ Contenu du cours

ORM, annotations JPA, relations, transactions et JNDI avec diagrammes.

◈ Concepts clés

JPA vs JDBC, fetch types, cascade, états d'entité, CMT vs BMT, glossaire.

⟨/⟩ Exemples de code

Entités JPA, relations, JPQL, Criteria API, Repository, persistence.xml, Flyway.
