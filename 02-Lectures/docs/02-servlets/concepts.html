Glossaire

TermeDéfinition
ServletClasse Java qui gère des requêtes HTTP côté serveur, compilée et exécutée dans un conteneur web
JSPJavaServer Pages — technologie permettant de créer des pages HTML dynamiques avec du Java embarqué, compilées en servlets
ELExpression Language — syntaxe simplifiée ${expression} pour accéder aux données dans JSP
JSTLJSP Standard Tag Library — bibliothèque de tags pour l'itération, les conditions, le formatage (alternative aux scriptlets)
MVCModel-View-Controller — pattern architectural séparant données (Model), présentation (View) et contrôle (Controller)
PRGPost-Redirect-Get — pattern évitant les doubles soumissions de formulaire en redirigeant après un POST
Filter ChainChaîne de filtres traversée dans l'ordre avant/après le servlet — chaque filtre appelle chain.doFilter()
JSESSIONIDNom du cookie standard Jakarta EE stockant l'identifiant de session côté client
