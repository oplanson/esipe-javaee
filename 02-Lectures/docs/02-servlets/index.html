Servlets, JSP & MicroProfile

Construction d'applications web dynamiques — Durée : 3h · Instructeur : Olivier Planson

Servlet 6.0 JSP JSTL Filters Listeners MP Config MP Health

Objectifs pédagogiques

✅Comprendre le cycle de vie complet d'un servlet
✅Créer des pages web dynamiques avec JSP et JSTL
✅Implémenter le pattern MVC dans les applications web
✅Utiliser MicroProfile Config dans la couche web
✅Ajouter des health checks pour les composants web
✅Construire une interface web bancaire complète

Plan du cours

  1. Cycle de vie des Servlets — init, service, destroy
  2. Méthodes HTTP — doGet, doPost, doPut, doDelete
  3. Configuration des Servlets — annotations et web.xml
  4. Objets Request et Response
  5. JavaServer Pages (JSP) — syntaxe, EL, JSTL
  6. Pattern MVC — Model, View, Controller
  7. MicroProfile Config dans la couche web
  8. Health Checks pour les applications web
  9. Session HTTP — gestion d'état, sécurité
  10. Filtres et Listeners Servlet

☰ Contenu du cours

Cycle de vie, JSP, MVC, Filtres, Listeners avec images de diagrammes.

◈ Concepts clés

Servlet vs JSP, MVC pattern, JSTL vs scriptlets, Filters ordering.

⟨/⟩ Exemples de code

Servlets complets, JSP avec JSTL, Filtres, Health checks, session.
