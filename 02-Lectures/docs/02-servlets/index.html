Servlets, JSP & MicroProfile

Building dynamic web applications — Duration: 3h · Instructor: Olivier Planson

Servlet 6.0 JSP JSTL Filters Listeners MP Config MP Health

Learning Objectives

✅Understand the complete servlet lifecycle
✅Create dynamic web pages with JSP and JSTL
✅Implement the MVC pattern in web applications
✅Use MicroProfile Config in the web layer
✅Add health checks for web components
✅Build a complete banking web interface

Course Outline

  1. Servlet lifecycle — init, service, destroy
  2. HTTP methods — doGet, doPost, doPut, doDelete
  3. Servlet configuration — annotations and web.xml
  4. Request and Response objects
  5. JavaServer Pages (JSP) — syntax, EL, JSTL
  6. MVC pattern — Model, View, Controller
  7. MicroProfile Config in the web layer
  8. Health Checks for web applications
  9. HTTP Session — state management, security
  10. Servlet Filters and Listeners
