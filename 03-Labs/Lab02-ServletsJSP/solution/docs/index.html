Banking Web Application

Application web bancaire construite avec Jakarta EE 10 et MicroProfile 6.0, déployée sur Open Liberty. Elle gère les clients et leurs comptes via un pattern MVC Servlet/JSP avec des filtres transversaux et des health checks.
