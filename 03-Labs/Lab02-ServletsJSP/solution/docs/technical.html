Architecture Technique

Architecture en couches Jakarta EE déployée dans un WAR sur Open Liberty. Pas de persistance externe dans ce lab — le stockage est en mémoire (ConcurrentHashMap). MicroProfile Config, Health et Metrics sont activés via la feature Liberty.

Diagramme en couches

APIs Jakarta EE utilisées

API Jakarta EEVersionUsage dans l'application
jakarta.servlet6.0HttpServlet, Filter, @WebServlet, @WebFilter, RequestDispatcher
jakarta.servlet.jsp3.1Vues JSP dans WEB-INF/views/, EL expressions ${}
jakarta.servlet.jsp.jstl3.0Tags <c:forEach>, <c:if>, <c:out>, <fmt:formatNumber>
jakarta.servlet.http6.0HttpSession, HttpServletRequest/Response, HttpServletResponseWrapper

APIs MicroProfile utilisées

API MicroProfileVersionUsage
MicroProfile Config3.0Configuration externalisée via microprofile-config.properties, injectée dans Liberty via web.xml context-params
MicroProfile Health4.0DatabaseHealthCheck (liveness) et WebAppReadinessCheck (readiness) — exposées sur /health
MicroProfile Metrics5.0Métriques JVM et applicatives exposées sur /metrics
