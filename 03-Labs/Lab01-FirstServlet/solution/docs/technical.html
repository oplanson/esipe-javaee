Composants principaux

Servlet

WelcomeServlet

Classe : com.bank.web.WelcomeServlet
Annotation : @WebServlet(name="WelcomeServlet", urlPatterns={"/welcome"})
Méthodes : doGet(), getServletInfo()
Logique : récupère LocalDateTime.now(), formate avec pattern "EEEE, MMMM dd, yyyy 'at' HH:mm:ss", écrit le HTML via PrintWriter.

Servlet

ClientListServlet

Classe : com.bank.web.ClientListServlet
Annotation : @WebServlet(name="ClientListServlet", urlPatterns={"/clients"})
Champ : private final List<Client> clients = new CopyOnWriteArrayList<>()
Méthodes : init(), doGet(), doPost(), escapeHtml(), getServletInfo()

Étapes du Containerfile

ÉtapeInstructionDescription
1FROM icr.io/appcafe/open-liberty:full-java17-openj9-ubiImage de base IBM Container Registry — Java 17, OpenJ9, Red Hat UBI
2COPY --chown=1001:0 target/banking-app.war /config/apps/Copie du WAR compilé dans le répertoire d'applications explicites (pas dropins)
3COPY --chown=1001:0 src/main/liberty/config/server.xml /config/Configuration du serveur Open Liberty (features, endpoints, webApplication)
4COPY --chown=1001:0 src/main/liberty/config/bootstrap.properties /config/Variables de démarrage (ports HTTP/HTTPS, context root)
5COPY --chown=1001:0 src/main/resources/META-INF/microprofile-config.properties /config/Configuration MicroProfile (health, metrics, openapi)
6RUN configure.shScript Liberty — installe les features déclarées dans server.xml, optimise l'image
7EXPOSE 9080 9443Expose les ports HTTP (9080) et HTTPS (9443)
8CMD ["/opt/ol/wlp/bin/server", "run", "defaultServer"]Démarrage d'Open Liberty en foreground dans le conteneur

Commandes d'exploitation

Build Maven

mvn clean package

Compile les sources Java, exécute les tests, package le WAR dans target/banking-app.war.

Build de l'image

podman build -t banking-app:lab01 \
  -f Containerfile .

Construit l'image OCI. Nécessite que le WAR soit présent dans target/.

Exécution du conteneur

podman run -d \
  --name banking-app-lab01 \
  -p 9080:9080 \
  -p 9443:9443 \
  banking-app:lab01

Lance le conteneur en mode détaché. Application accessible sur http://localhost:9080/.
