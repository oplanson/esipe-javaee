SD1 — GET /welcome — Page de bienvenue

#ParticipantActionDétail
1NavigateurGET /welcomeRequête HTTP vers le serveur Open Liberty

3WelcomeServletsetContentTyperesponse.setContentType("text/html;charset=UTF-8")
