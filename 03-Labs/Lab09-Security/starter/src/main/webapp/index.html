🔐 Bank Security Application

Lab 9: Jakarta EE Security
This application demonstrates JWT authentication, role-based access control, and security audit logging.

Authentication Endpoints

POST /api/auth/register - Register new user
POST /api/auth/login - Login and get JWT token
POST /api/auth/logout - Logout (audit only)
GET /api/auth/me - Get current user info

Account Endpoints

GET /api/accounts ADMIN, MANAGER - Get all accounts
GET /api/accounts/my ALL ROLES - Get my accounts
GET /api/accounts/{id} ALL ROLES - Get account by ID
POST /api/accounts TELLER, MANAGER, ADMIN - Create account
POST /api/accounts/{id}/deposit TELLER, MANAGER, ADMIN - Deposit money
POST /api/accounts/{id}/withdraw TELLER, MANAGER, ADMIN - Withdraw money
POST /api/accounts/transfer MANAGER, ADMIN - Transfer money
DELETE /api/accounts/{id} ADMIN - Delete account

Health & Metrics

GET /health/live - Liveness probe
GET /health/ready - Readiness probe
GET /metrics - Application metrics

Security Features

  • ✅ JWT Token Authentication
  • ✅ Role-Based Access Control (RBAC)
  • ✅ Password Hashing (PBKDF2 with 310,000 iterations)
  • ✅ Account Lockout (5 failed attempts)
  • ✅ Security Audit Logging
  • ✅ Security Headers (CSP, X-Frame-Options, etc.)
  • ✅ CORS Configuration

User Roles

  • CUSTOMER - Can view own accounts
  • TELLER - Can create accounts, deposit, withdraw
  • MANAGER - Can transfer money, view all accounts
  • ADMIN - Full access including delete
