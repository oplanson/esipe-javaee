Cycle de vie du token JWT

Schéma de base de données PostgreSQL

Table users

  • id — BIGSERIAL PK
  • username — VARCHAR UNIQUE NOT NULL
  • email — VARCHAR UNIQUE NOT NULL
  • password — TEXT (hash PBKDF2)
  • enabled — BOOLEAN DEFAULT true
  • account_locked — BOOLEAN DEFAULT false
  • failed_login_attempts — INT DEFAULT 0
  • last_login — TIMESTAMP
  • created_at — TIMESTAMP DEFAULT NOW()

Table user_roles

  • user_id — BIGINT FK → users.id
  • role — VARCHAR (ADMIN|MANAGER|TELLER|CUSTOMER)

Table accounts

  • id — BIGSERIAL PK
  • account_number — VARCHAR UNIQUE
  • owner_username — VARCHAR NOT NULL
  • balance — DECIMAL(15,2)
  • account_type — VARCHAR
  • created_at — TIMESTAMP

Table security_audit_logs

  • id — BIGSERIAL PK
  • timestamp — TIMESTAMP NOT NULL
  • username — VARCHAR
  • action — VARCHAR (LOGIN/LOGOUT/ACCESS…)
  • resource — VARCHAR
  • result — VARCHAR (SUCCESS/FAILURE/DENIED)
  • ip_address — VARCHAR
  • user_agent — TEXT
  • details — TEXT

Configuration Open Liberty

Features Liberty

  • webProfile-10.0
  • microProfile-6.1
  • applicationSecurity-5.0 / 6.0
  • jdbc-4.2

Paramètres de sécurité

  • jwt.secret — minimum 256 bits (HS256)
  • jwt.expiration.hours = 24
  • security.max.failed.attempts = 5
  • security.account.lockout.duration.minutes = 30

Catalogue des endpoints REST

AuthResource — Authentification (/api/auth)

MéthodeCheminAccèsDescription
POST /api/auth/login Public Authentification par identifiants, retourne un token JWT
POST /api/auth/register Public Inscription — rôle CUSTOMER assigné automatiquement
POST /api/auth/logout @PermitAll Déconnexion (tout utilisateur authentifié)
GET /api/auth/me @PermitAll Profil de l'utilisateur courant

AccountResource — Comptes (/api/accounts)

MéthodeCheminRôlesDescription
GET /api/accounts ADMIN MANAGER Liste tous les comptes
GET /api/accounts/my Tous les rôles Comptes de l'utilisateur connecté
GET /api/accounts/{id} Tous les rôles + ownership CUSTOMER Détail d'un compte
POST /api/accounts ADMIN MANAGER TELLER Crée un nouveau compte
POST /api/accounts/{id}/deposit ADMIN MANAGER TELLER Dépôt sur un compte
POST /api/accounts/{id}/withdraw ADMIN MANAGER TELLER Retrait depuis un compte
POST /api/accounts/transfer ADMIN MANAGER Virement entre comptes
DELETE /api/accounts/{id} ADMIN Suppression d'un compte
