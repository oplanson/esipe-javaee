DataSources

FlywayDataSource

maxPool=5

DataSource dédiée aux migrations Flyway. Pool limité à 5 connexions. Utilisée uniquement lors de la phase de démarrage (contextInitialized).

DefaultDataSource / jdbc/bankingDS

maxPool=10 JTA

DataSource principale. Pool de 10 connexions. Référencée dans persistence.xml et dans web.xml via <resource-ref>.

Migrations Flyway

VersionScriptContenu
V1 V1__create_clients.sql Table clients (id, name, email, created_at, updated_at)
V2 V2__create_accounts.sql Table accounts avec client_id REFERENCES clients(id) ON DELETE CASCADE
V3 V3__add_status.sql Colonne status VARCHAR(20) DEFAULT 'ACTIVE' sur accounts
