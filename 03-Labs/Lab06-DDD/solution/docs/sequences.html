Diagrammes de Séquences

5 diagrammes SVG inline représentant les flux principaux de l'application : lecture de la liste clients (Web), lecture de la liste comptes (REST v2), création de compte avec validation (Web), démarrage de l'application, et gestion des erreurs HTTP.

SD1 — Affichage de la liste des clients (GET /clients)

ÉtapeActeur sourceActeur cibleMessage
1NavigateurClientControllerGET /clients
2ClientControllerClientServiceclientService.findAll() — @Transactional(SUPPORTS)
3ClientServiceEntityManagerNamedQuery Client.findAll
4EntityManagerPostgreSQLSELECT FROM clients ORDER BY name
5ClientController—req.setAttribute("clients"), req.setAttribute("appName")
6ClientControllerNavigateurforward → client-list.jsp → 200 OK HTML

SD2 — Lecture de la liste des comptes REST v2 (GET /api/v2/accounts)

ÉtapeActeur sourceActeur cibleMessage
1API ClientAccountResourceV2GET /api/v2/accounts — Accept: application/json
2AccountResourceV2AccountServiceaccountService.findAll() — @Logged @Transactional(SUPPORTS)
3AccountServiceEntityManagerNamedQuery Account.findAll ORDER BY account_number
4EntityManagerPostgreSQLSELECT FROM accounts JOIN clients
5AccountResourceV2—Stream().map(AccountDTO::fromEntity) — mapping entité→Record Java 17
6AccountResourceV2API Client200 OK — JSON [AccountDTO] avec header X-API-Version:2.0

SD3 — Création d'un compte (POST /account — Web avec validation)

ÉtapeActeur sourceActeur cibleMessage
1NavigateurAccountControllerPOST /account — action=create, clientId, type, balance, number
2aAccountController—parseAccountCreationRequest() — si type/clientId manquant → 302 redirect avec error=type_required
2bAccountControllerAccountServiceclientService.findById(clientId) — vérification client existe
3AccountController—Account.create(client, AccountType.valueOf(type), Money.euros(balance)) — factory method, génère AccountNumber IBAN
4AccountControllerAccountServiceaccountService.create(account, clientId) — @Transactional
5AccountServicePostgreSQLem.persist(account) + em.flush() — INSERT INTO accounts avec balance_amount, balance_currency
6AccountServiceCDI Event BusaccountCreatedEvent.fire(AccountCreatedEvent) — BankingEventObserver reçoit et envoie notification
7AccountControllerNavigateur302 Redirect → /client?action=view&id=N&message=account_created (PRG Pattern)
8NavigateurAccountControllerGET /client?action=view → 200 OK avec banner de confirmation
