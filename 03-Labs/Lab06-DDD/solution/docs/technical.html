Architecture Technique

Architecture en couches DDD sur Jakarta EE 10 avec Open Liberty 23. La couche domaine est indépendante de l'infrastructure — les Value Objects, Aggregates et Domain Services ne dépendent d'aucun framework.

Composants principaux

EntityManagerProducer

CDI Producer @ApplicationScoped. Expose l'EntityManager (@RequestScoped) depuis le @PersistenceContext(bankingPU) et produit des Logger contextuels via InjectionPoint.

LoggingInterceptor

Intercepteur CDI activé par l'annotation @Logged. Loggue l'entrée/sortie de méthode avec paramètres, durée d'exécution et exceptions. Priorité APPLICATION.

BankingEventObserver

Observer CDI @ApplicationScoped écoutant ClientCreatedEvent, AccountCreatedEvent et TransactionEvent. Sélectionne PremiumNotificationService ou StandardNotificationService via les qualifiers @Premium/@Standard.

TransferService (Domain Service)

Service domaine @ApplicationScoped @Transactional coordonnant le virement entre deux aggregates Account. Calcule les frais (standard 1%, min 1€, max 50€ ; premium gratuit).

RestApplicationV2

@ApplicationPath("/api/v2"). Enregistrement explicite de AccountResourceV2 uniquement, évitant l'autodécouverte des ressources v1. Pattern recommandé pour le versioning d'API.

Exception Mappers

NotFoundExceptionMapper → HTTP 404, ValidationExceptionMapper → HTTP 400, ConstraintViolationExceptionMapper → HTTP 400, GenericExceptionMapper → HTTP 500. Tous produisent un ErrorResponse JSON.

Configuration Sécurité / Session

web.xml — session-config

Timeout de session : 30 minutes. Cookie HttpOnly: true, Secure: false (HTTP en dev). Pas d'authentification configurée (application pédagogique). La suppression de clients et comptes est contrôlée par les feature flags feature.client.deletion.enabled et feature.account.deletion.enabled injectés via @ConfigProperty.

Commandes de déploiement

Démarrage local (dev)

# Démarrer PostgreSQL
docker-compose up -d postgres

# Dev mode Liberty (hot reload)
mvn liberty:dev

Build image container

# Compiler + packager
mvn clean package

# Construire l'image OCI
podman build -t banking-ddd-app:lab06 .

Lancer le container

podman run -d \
  -p 9080:9080 \
  -e db_host=host.containers.internal \
  -e db_password=bankpass \
  --name banking-lab06 \
  banking-ddd-app:lab06
