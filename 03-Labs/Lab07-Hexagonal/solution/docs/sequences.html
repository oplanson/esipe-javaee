Diagrammes de Séquence

Trois scénarios clés illustrant le flux d'appel complet à travers toutes les couches hexagonales : adaptateur primaire → port primaire → service applicatif → domaine → port secondaire → adaptateur secondaire.

SD1 — Dépôt via REST V2

Séquence complète d'un dépôt monétaire via l'adaptateur primaire REST v2, incluant la validation, la persistance et la publication d'événement.

SD2 — Transfert avec Calcul de Frais

Virement entre deux comptes incluant le calcul des frais selon le statut client (premium = gratuit, standard = 1% min 1€ max 50€).

SD3 — Création Client et Passage Premium

Deux appels REST successifs : création d'un client puis montée en grade premium.
