Gestion des transactions

CMT — Container-Managed Transactions

Mode par défaut pour les EJBs. Le conteneur démarre, suspend, commit ou rollback les transactions automatiquement selon l'annotation @TransactionAttribute.

BMT — Bean-Managed Transactions

Utilisé par DatabaseMigrationStartup via @TransactionManagement(BEAN). Le bean contrôle explicitement la transaction via UserTransaction injecté. 

@TransactionManagement(TransactionManagementType.BEAN)
@Singleton @Startup
public class DatabaseMigrationStartup {
    @Resource UserTransaction utx;

    @PostConstruct
    public void migrate() throws Exception {
        utx.begin();
        try {
            flyway.migrate();
            utx.commit();
        } catch (Exception e) {
            utx.rollback();
            throw e;
        }
    }
}
