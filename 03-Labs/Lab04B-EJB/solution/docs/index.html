EJB Types démontrés

@Stateless

Pool d'instances géré par le container. Aucun état conversationnel entre les appels. CMT par défaut.

AccountServiceBean, ClientServiceBean

@Stateful

Instance dédiée par client. Maintient un état entre les appels jusqu'à @Remove. Timeout 30 min.

TransactionBatchBean

@Singleton + @Startup

Instance unique dans la JVM. Initialisé au démarrage. @Lock(READ/WRITE) pour la concurrence.

ConfigServiceBean, DatabaseMigrationStartup, ReportGeneratorBean

@MessageDriven

Consommateur JMS asynchrone. Écoute la queue jms/notificationQueue. Supporte EMAIL/SMS/PUSH/ALERT.

NotificationMDB
