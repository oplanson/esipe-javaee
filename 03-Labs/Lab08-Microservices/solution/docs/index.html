Banking Microservices Architecture

Architecture microservices complète en 3 services indépendants avec pattern BFF/API Gateway, communication REST inter-services et résilience MicroProfile Fault Tolerance.

ℹ️
Lab 08 — Architecture microservices complète : 3 services indépendants (Client, Account, API Gateway BFF), communication REST avec MicroProfile Fault Tolerance et pattern Database per Service.

Les 3 services

👤 Client Service

Port 9081 PostgreSQL :5433

Gestion du cycle de vie des clients bancaires. CRUD complet, gestion premium, validations Jakarta Bean Validation.

  • ClientResource — API REST @Path /api/clients
  • ClientService — @ApplicationScoped @Transactional
  • ClientRepository — port hexagonal
  • ClientRepositoryAdapter — implémentation JPA
  • ClientEntity + ClientDTO + ClientMapper
  • ClientServiceHealthCheck — @Readiness
  • ClientServiceLivenessCheck — @Liveness
  • DatabaseMigrationStartup — Flyway
  • Base de données : bank_client_db (port 5433)

💳 Account Service

Port 9082 PostgreSQL :5434 Fault Tolerance

Gestion des comptes bancaires avec appel inter-service vers Client Service pour valider l'existence du client.

  • AccountResource — API REST @Path /api/accounts
  • AccountService — @ApplicationScoped @Transactional
  • ClientServiceClient — @RegisterRestClient @Retry @Timeout @CircuitBreaker @Fallback
  • AccountRepository + AccountRepositoryAdapter
  • AccountEntity + AccountDTO + TransactionDTO
  • Statuts : ACTIVE / SUSPENDED / CLOSED
  • Types : CHECKING / SAVINGS / BUSINESS
  • Base de données : banking_account_db (port 5434)

🌐 API Gateway / BFF

Port 9080 BFF Pattern Fault Tolerance

Backend For Frontend : agrégation des données des deux services, proxy transparent et résilience complète.

  • BankingResource — @Path /banking (agrégation)
  • AccountProxyResource — proxy /api/accounts
  • ClientProxyResource — proxy /api/clients
  • BankingAggregationService — @Retry @CircuitBreaker @Bulkhead(10)
  • AccountServiceClient + ClientServiceClient
  • ClientWithAccountsDTO — client + comptes + totalBalance + accountCount
  • ServicesHealthCheck — @Readiness (vérifie les 2 services)
  • GatewayLivenessCheck — @Liveness
