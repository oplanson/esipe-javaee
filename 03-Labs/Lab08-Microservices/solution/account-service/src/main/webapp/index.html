Features

  • Account creation and management
  • Deposit and withdrawal operations
  • Account-to-account transfers
  • Account status management (Active, Suspended, Closed)
  • Client verification via REST client
  • Fault tolerance with Circuit Breaker
  • Automatic retry on failures
  • Database migration with Flyway
  • Health checks and metrics

MicroProfile Features

  • Fault Tolerance: Circuit Breaker, Retry, Timeout, Fallback
  • Health: Readiness and liveness probes
  • Metrics: Application metrics exposure
  • OpenAPI: Automatic API documentation
