🏦 Banking Application

Microservices Architecture with BFF Pattern - Lab 08

Welcome to the Banking Microservices Application

This application demonstrates a complete microservices architecture with:

  • Backend For Frontend (BFF) - API Gateway with web interface
  • Client Service - Manages client information
  • Account Service - Manages bank accounts and transactions
  • Service Aggregation - Combines data from multiple services
  • Fault Tolerance - Circuit breaker, retry, timeout, fallback

Architecture Overview

🌐 API Gateway / BFF

Port: 9080

Role: Web UI + Service Aggregation

Features:

  • JSP-based web interface
  • Data aggregation from backend services
  • MicroProfile Rest Client
  • Comprehensive fault tolerance

👤 Client Service

Port: 9081

Role: Client Management

Features:

  • REST API for clients
  • PostgreSQL database
  • Hexagonal architecture
  • Health checks & metrics

💳 Account Service

Port: 9082

Role: Account & Transaction Management

Features:

  • REST API for accounts
  • PostgreSQL database
  • Client verification via REST client
  • Fault tolerance patterns
