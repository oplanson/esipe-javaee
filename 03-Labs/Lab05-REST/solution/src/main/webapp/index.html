JAX-RS Features

  • ✅ RESTful Resources (@Path, @GET, @POST, @PUT, @DELETE)
  • ✅ JSON-B Serialization (@Produces, @Consumes)
  • ✅ Bean Validation (@Valid, @NotNull)
  • ✅ Exception Mappers (@Provider)
  • ✅ Transaction Management (Deposits, Withdrawals, Transfers)
  • ✅ Transaction History & Filtering
  • ✅ MicroProfile OpenAPI (@OpenAPIDefinition)
  • ✅ MicroProfile Rest Client (@RegisterRestClient)
