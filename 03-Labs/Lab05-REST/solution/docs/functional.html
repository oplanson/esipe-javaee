Architecture Fonctionnelle

Cinq domaines fonctionnels : API Clients, API Comptes, API Transactions (audit), Gestion des erreurs, et composants CDI transversaux. Le tout exposé sous /api via JAX-RS 3.1.

5. CDI Transversal

EntityManagerProducer

@Produces un EntityManager @RequestScoped injecté dans tous les services via @Inject. Produit également un Logger nommé par classe (@Produces @Dependent).

LoggingInterceptor @Logged

Intercepteur CDI activé par l'annotation @Logged. Trace l'entrée, la sortie et la durée d'exécution de chaque méthode interceptée via le Logger injecté.

BankingEventObserver

Observe 3 types d'événements via @Observes :
• ClientCreatedEvent
• TransactionEvent (dépôt / retrait)
• TransferEvent (virement)

Qualifiers de notification

@Premium — tous les canaux : email + SMS + push.
@Standard — email uniquement, seulement si montant > 1 000 €.
Sélectionnés par CDI à l'injection dans BankingEventObserver.
