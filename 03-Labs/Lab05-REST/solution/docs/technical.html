Architecture Technique

Quatre couches clairement délimitées : JAX-RS, CDI Services, JPA / EclipseLink, et PostgreSQL + Flyway. Le tout déployé sur Open Liberty 23 avec MicroProfile 6.0.

Entités JPA

Client

@Entity — représente un titulaire de compte.

  • @NotNull @Size(min=2, max=100) sur name
  • @NotNull @Email sur email (unique)
  • @OneToMany(mappedBy="client", cascade=ALL, orphanRemoval=true) → List<Account>
  • 4 NamedQueries : findAll, findById, findByName, count

Account

@Entity — représente un compte bancaire.

  • @NotNull @Size(min=5, max=34) sur accountNumber (unique)
  • @NotNull @DecimalMin("0.0") sur balance
  • @ManyToOne @JsonbTransient sur client (évite la récursion JSON)
  • Méthodes métier : deposit(amount), withdraw(amount) avec validation solde
  • 4 NamedQueries : findAll, findById, findByClient, findByType

Transaction

@Entity — enregistrement d'audit immuable.

  • Type enum : DEPOSIT, WITHDRAWAL, TRANSFER_OUT, TRANSFER_IN
  • Champs d'audit : balanceBefore, balanceAfter, transactionDate
  • 5 NamedQueries : findAll, findById, findByAccount, findByType, findByDateRange
  • Toutes les requêtes triées ORDER BY transactionDate DESC

Configuration MicroProfile REST Client

banking-api/mp-rest/url=http://localhost:9080
banking-api/mp-rest/connectTimeout=5000
banking-api/mp-rest/readTimeout=10000

BankingRestClient est annoté @RegisterRestClient(configKey="banking-api"). Il permet à l'application d'appeler sa propre API REST ou une instance distante sans manipulation manuelle de HttpClient.
