🚀 Lab 05B: JMS Enterprise Messaging

Jakarta Messaging (JMS) 3.1 - Asynchronous Communication

📋 Lab Overview

This lab demonstrates enterprise messaging using Jakarta Messaging (JMS) 3.1. You'll learn how to implement asynchronous communication patterns, message-driven beans, and error handling in a banking application.

✨ Features Implemented

📨 Message Producers

Send transaction events to JMS queues and topics using the simplified JMS 3.1 API with CDI integration.

🎯 Message-Driven Beans

Process messages asynchronously with MDBs for email notifications, audit logging, and transaction processing.

📊 Audit Logging

Durable topic subscription for audit events with database persistence for compliance.

💀 Dead Letter Queue

Handle failed messages after maximum redelivery attempts with comprehensive error logging.

📧 Email Notifications

Asynchronous email notifications for transaction events with message selectors.

🔄 Transaction Management

JTA transaction integration with JMS for reliable message processing.
