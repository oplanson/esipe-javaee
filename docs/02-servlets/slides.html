🔄 Servlet Lifecycle

A servlet is a Java class that handles HTTP requests and generates dynamic responses.

Lifecycle phases:

  • Loading & Instantiation — class loaded by the container
  • init() — resource initialisation (called once)
  • service() — handles each HTTP request
  • destroy() — resource release (called once)
🔄 HTTP Methods — doGet, doPost
  • doGet() — data retrieval, search, resource listing
  • doPost() — form submission, resource creation
  • doPut() — full resource update
  • doDelete() — resource deletion

PRG pattern (Post-Redirect-Get): after a successful POST, redirect to a GET to avoid double submissions.

🎨 JavaServer Pages (JSP)

JSP is a technology for creating dynamic web pages with embedded Java HTML.

JSP syntax elements:

  • Directives <%@ page ... %> — page configuration
  • Scriptlets <% ... %> — Java blocks (to avoid)
  • Expressions <%= ... %> — value display
  • EL (Expression Language) ${...} — simplified data access
  • JSTL — standard tags for iteration, conditions, formatting

Best practice: Avoid scriptlets — use JSTL and EL!

🏗️ MVC Pattern

Responsibilities:

  • Model — business logic, data access (Java classes, JPA entities)
  • View — presentation layer (JSP, HTML, CSS)
  • Controller — request handling, flow control (Servlets)
⚙️ MicroProfile Config in the Web Layer
  • Externalise configuration (URLs, limits, feature flags)
  • Environment-specific parameters (dev, test, prod)
  • Configuration sources (decreasing priority): system properties → env vars → microprofile-config.properties
💊 Health Checks — Liveness and Readiness
  • Liveness — is the application running?
  • Readiness — is the application ready to handle requests?
  • Startup — has the application started successfully?

Endpoints: /health · /health/live · /health/ready · /health/started

🔐 HTTP Session
  • Maintains user state in the stateless HTTP protocol
  • Identified by session ID (JSESSIONID cookie)
  • Session fixation prevention: invalidate the old session before the new one
  • Protection: HttpOnly + Secure flags on cookies, configured timeout
🔍 Servlet Filters

Filters intercept requests/responses for cross-cutting concerns:

  • Authentication and authorisation
  • Logging and audit
  • Request/response modification
  • Compression and encryption
  • CORS management
👂 Servlet Listeners

Listeners react to lifecycle events:

  • ServletContextListener — application start/stop
  • HttpSessionListener — session creation/destruction
  • ServletRequestListener — start/end of each request
