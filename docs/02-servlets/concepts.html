Glossary

TermDefinition
ServletJava class that handles HTTP requests server-side, compiled and executed in a web container
JSPJavaServer Pages — technology for creating dynamic HTML pages with embedded Java, compiled into servlets
ELExpression Language — simplified syntax ${expression} for data access in JSP
JSTLJSP Standard Tag Library — tag library for iteration, conditions, formatting (alternative to scriptlets)
MVCModel-View-Controller — architectural pattern separating data (Model), presentation (View) and control (Controller)
PRGPost-Redirect-Get — pattern avoiding double form submissions by redirecting after a POST
Filter ChainChain of filters traversed in order before/after the servlet — each filter calls chain.doFilter()
JSESSIONIDName of the standard Jakarta EE cookie storing the session identifier client-side
