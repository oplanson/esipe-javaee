Microservices Architecture

From monolith to microservices — Duration: 4h · Instructor: Olivier Planson

Microservices API Gateway Circuit Breaker Docker Compose Saga Service Discovery

Learning Objectives

✅Understand the principles of microservices architecture
✅Decompose monolithic applications into services
✅Implement inter-service communication
✅Apply the API Gateway pattern
✅Configure Service Discovery and externalized configuration
✅Implement distributed tracing and monitoring
✅Manage data consistency in distributed systems
✅Deploy microservices with Docker Compose

Course Outline

  1. What are microservices — definition and comparison
  2. Benefits and challenges of microservices
  3. Decomposition strategies — Domain decomposition
  4. Inter-service communication — REST and asynchronous
  5. API Gateway pattern
  6. Service Discovery and configuration
  7. Observability — tracing, logging, metrics
  8. Data consistency — Saga, CQRS, Event Sourcing
  9. Deployment with Docker Compose
  10. Deployment patterns and CI/CD

☰ Course Content

Monolith vs microservices, DDD decomposition, inter-service communication, API Gateway, observability, Saga, Docker Compose with diagrams.

◈ Key Concepts

Comparisons, communication strategies, microservices patterns, observability pillars, CAP theorem and glossary.

⟨/⟩ Code Examples

Fault Tolerance, API Gateway, MicroProfile Config, Health Check, Saga choreography, Docker Compose, correlation ID.

⧫ Microservices Patterns

API Gateway, Circuit Breaker, Database per Service, Saga, CQRS and Event Sourcing — with SVG diagrams.
