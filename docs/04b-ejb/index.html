EJB — Enterprise Java Beans

Jakarta EE 10 — Duration: 3h · Instructor: Olivier Planson

EJB @Stateless @Stateful JTA @Singleton @MessageDriven

Learning Objectives

✅Understand EJB architecture and container services
✅Implement Stateless/Stateful/Singleton Session Beans
✅Create Message-Driven Beans for asynchronous processing
✅Manage transactions with CMT and BMT
✅Implement declarative and programmatic security
✅Use the Timer Service for scheduled tasks
✅Create asynchronous methods
✅Compare EJB vs CDI and choose appropriately

Course Outline

  1. EJB architecture and container services
  2. Stateless Session Beans
  3. Stateful Session Beans
  4. Singleton Session Beans
  5. Message-Driven Beans (MDB)
  6. CMT and BMT transaction management
  7. EJB Security (declarative and programmatic)
  8. Timer Service and asynchronous methods

☰ Course Content

EJB architecture, Session Beans, MDB, transactions, security and timers with diagrams.

◈ Key Concepts

EJB vs CDI, bean types, transaction attributes, declarative security, patterns and glossary.

⟨/⟩ Code Examples

Stateless, Stateful, Singleton, MDB, declarative security and Timer Service.
