Hint 1 — why domain events?Indice 1 — pourquoi des événements de domaine ?

A domain event decouples the code that causes a change from the code that reacts to it. Here, MoneyDepositedEvent is picked up by BankingEventObserver to log an audit trail. public Money calculateTransferFee(Money amount, boolean isPremiumClient) {
    if (isPremiumClient) return Money.zero(amount.getCurrency());
    Money fee = amount.multiply(0.01);
    Money min = Money.of(1.0, amount.getCurrency());
    Money max = Money.of(50.0, amount.getCurrency());
    if (fee.isLessThan(min)) return min;
    if (fee.isGreaterThan(max)) return max;
    return fee;
}
