01Goal of the labObjectif du lab

You build a small client management web application for the banking case study that runs through the whole course. Vous construisez une petite application web de gestion de clients pour le cas d'étude bancaire qui sert de fil rouge au cours. Elle est volontairement simple : pas de base de données ni de framework, uniquement des servlets, pour voir précisément ce que fait l'API Servlet.

The redeploy loopLa boucle de redéploiement

The WAR is baked into the container image, so after every change you rebuild and restart. You will use these commands many times: Le WAR est embarqué dans l'image du conteneur : après chaque modification, vous reconstruisez et relancez. Vous utiliserez ces commandes de nombreuses fois : 

mvn clean package -DskipTests
podman rm -f banking-lab01 2>/dev/null
podman build -t banking-app:lab01 -f Containerfile .
podman run -d --name banking-lab01 -p 127.0.0.1:9080:9080 banking-app:lab01
until curl -fs http://localhost:9080/ >/dev/null; do sleep 2; done; echo "ready"

The container is bound to 127.0.0.1 so the application is reachable from your machine only. The first mvn package downloads Open Liberty and may take several minutes; later builds are faster. This loop works from step 2 on, once the Containerfile exists. Le conteneur est lié à 127.0.0.1 : l'application n'est accessible que depuis votre machine. Le premier mvn package télécharge Open Liberty et peut prendre plusieurs minutes ; les suivants sont plus rapides. Cette boucle fonctionne à partir de l'étape 2, une fois le Containerfile créé.

@WebServlet(name = "WelcomeServlet", urlPatterns = {"/welcome"})
public class WelcomeServlet extends HttpServlet {

    private static final long serialVersionUID = 1L;

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html;charset=UTF-8");

        DateTimeFormatter formatter =
            DateTimeFormatter.ofPattern("EEEE, MMMM dd, yyyy 'at' HH:mm:ss");
        String formattedDateTime = LocalDateTime.now().format(formatter);

        try (PrintWriter out = response.getWriter()) {
            out.println("<!DOCTYPE html>");
            // ... html, head (meta charset, title, link css), body, container, card ...
            out.println("   " + formattedDateTime);
            // ... navigation list, footer, closing tags ...
        }
    }

    @Override
    public String getServletInfo() { return "..."; }
}

@Override
protected void doPost(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {
    String name  = request.getParameter("name");
    String email = request.getParameter("email");
    String phone = request.getParameter("phone");

    if (name == null || name.trim().isEmpty() /* same for email and phone */) {
        response.sendRedirect("add-client.html?error=missing");
        return;
    }

    Long newId = clients.stream().mapToLong(Client::getId).max().orElse(0L) + 1;
    Client newClient = new Client(newId, name.trim(), email.trim(), phone.trim());
    clients.add(newClient);
    log("New client added: " + newClient);
    response.sendRedirect("clients?message=success");
}
