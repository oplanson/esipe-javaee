01Goal of the labObjectif du lab

The business rules written in Lab 06 (value objects, aggregates, TransferService) stay in the middle. Around them you build explicit ports and move every technical detail (JPA, JAX-RS, servlets, CDI events) into adapters. The rule is simple: dependencies point inward; the domain knows nothing about the application layer, and the application layer knows nothing about the infrastructure. See slide 8. Les règles métier écrites au Lab 06 (objets-valeur, agrégats, TransferService) restent au centre. Autour d'elles, vous construisez des ports explicites et déplacez chaque détail technique (JPA, JAX-RS, servlets, événements CDI) dans des adaptateurs. La règle est simple : les dépendances pointent vers l'intérieur ; le domaine ne connaît rien de la couche application, et la couche application ne connaît rien de l'infrastructure. Voir la slide 8.

Visible change: the REST API moves from /api/clients and /api/accounts (Lab 06) to /api/v1/... (deprecated) and /api/v2/.... The JSP pages keep the URLs /clients and /accounts. Empty starter and inconsistencies in the lab files — read before you start

  • persistence.xml contains hibernate.* properties, but the runtime JPA provider of Open Liberty is EclipseLink: these properties are ignored.
  • bootstrap.properties sets db_host=postgres and db_name=bankingdb (Lab 06: localhost and bankdb). Without DB_* variables passed with -e, Liberty logs CWWKG0075E for ${db.port} and then cannot find jdbc/bankingDS. This guide passes the variables explicitly.
  • microprofile-config.properties still contains a db.url pointing to localhost/bankdb: it is not used.
  • docker-compose.yml publishes 5432:5432 on all interfaces. In this guide you write 127.0.0.1:5432:5432.
  • The scripts podman-test.sh, docker-test.sh, run-lab.sh, test-lab.sh are destructive (down -v, prune). Do not use them (see section Run).
  • ClientWebAdapter contains 15 System.out.println: use a Logger in your version.
  • server.xml enables com.bank.*=all logging: far too verbose; keep fine as in Lab 06.
  • httpEndpoint uses host="*" (all interfaces): acceptable in a container whose port you publish on 127.0.0.1 only.

Credentials shown in the lab files (bankuser / bankpass) are demo credentials and must never be reused in a real project.
