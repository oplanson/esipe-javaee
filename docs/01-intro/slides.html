🎯 What is Jakarta EE?

Jakarta EE (formerly Java EE) is a set of specifications for building enterprise Java applications.

Key characteristics:

  • Standards-based: Industry specifications
  • Vendor-independent: Multiple implementations available
  • Enterprise-ready: Designed for scalability and reliability
  • Open-source: Community development under Eclipse Foundation

🚀 What is MicroProfile?

Eclipse MicroProfile is a set of specifications optimised for microservices architecture.

Key characteristics:

  • Cloud-native: Designed for the cloud and containers
  • Microservices-oriented: Lightweight and modular
  • Complementary to Jakarta EE: Extends Jakarta EE capabilities
  • Rapid innovation: Shorter release cycles than Jakarta EE

📦 Jakarta EE Specifications

Web Technologies

  • Jakarta Servlet — HTTP request/response handling
  • Jakarta Server Pages (JSP) — Dynamic web pages
  • Jakarta Server Faces (JSF) — Component-oriented UI framework

Business Logic

  • Jakarta CDI — Dependency injection
  • Jakarta EJB — Business components

Data Persistence

  • Jakarta JPA — Object-relational mapping
  • Jakarta JTA — Transaction management
⚡ MicroProfile Specifications

Configuration

  • MP Config — Externalised configuration, dynamic updates

Observability

  • MP Health — Health endpoints
  • MP Metrics — Application metrics
  • MP OpenTracing — Distributed tracing

Resilience

  • MP Fault Tolerance — Circuit breakers, retries, timeouts
  • MP Rest Client — Type-safe REST clients
