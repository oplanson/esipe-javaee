Glossary

TermDefinition
Jakarta EEFormerly Java EE — platform of specifications for enterprise Java applications, managed by the Eclipse Foundation since 2017
MicroProfileSet of specifications complementary to Jakarta EE, targeting microservices and cloud-native architectures
Open LibertyIBM open-source application server implementing Jakarta EE 10 and MicroProfile 6, optimised for containers
PodmanOCI container management tool without daemon, compatible with Docker CLI, enabling rootless execution
WARWeb Application Archive — Java packaging format for web applications deployed on an application server
CDIContexts and Dependency Injection — standardised dependency injection mechanism of Jakarta EE
JPAJakarta Persistence API — specification for object-relational mapping (ORM) in Java
JAX-RSJakarta RESTful Web Services — API for creating REST services with Java annotations
