JPA & Database Integration

Jakarta Persistence API — Duration: 4h · Instructor: Olivier Planson

JPA 3.1 JPQL PostgreSQL JTA EntityManager Migrations

Learning Objectives

✅Understand Object-Relational Mapping (ORM)
✅Create and configure JPA entities
✅Define relationships between entities (1-1, 1-N, N-N)
✅Write JPQL and Criteria API queries
✅Manage transactions effectively (JTA vs resource-local)
✅Manage database schema migrations
✅Use JNDI for resources

Course Outline

  1. ORM and JPA architecture
  2. Basic annotations (@Entity, @Table, @Id)
  3. Relationships between entities
  4. JPQL — object-oriented queries
  5. Criteria API — dynamic queries
  6. Transaction management (JTA and resource-local)
  7. Migrations with Flyway
  8. JNDI and DataSource configuration

☰ Course Content

ORM, JPA annotations, relationships, transactions and JNDI with diagrams.

◈ Key Concepts

JPA vs JDBC, fetch types, cascade, entity states, JTA vs resource-local, glossary.

⟨/⟩ Code Examples

JPA entities, relationships, JPQL, Criteria API, Repository, persistence.xml, Flyway.
