CDI — Contexts and Dependency Injection

Jakarta Contexts and Dependency Injection — Duration: 3h · Instructor: Olivier Planson

CDI 4.0 @Inject Scopes Interceptors Events @Transactional

Learning Objectives

✅Understand the principles and benefits of dependency injection
✅Use CDI annotations to manage the bean lifecycle
✅Apply the different bean scopes
✅Implement qualifiers for type-safe injection
✅Use Producer Methods for creating complex objects
✅Apply declarative transaction management with @Transactional

Course Outline

  1. What is Dependency Injection — the new problem, CDI solution
  2. CDI Scopes — @ApplicationScoped, @RequestScoped, @SessionScoped, @Dependent
  3. Injection with @Inject — field, constructor, method injection
  4. CDI Qualifiers — @Qualifier, ambiguity resolution, @Alternative
  5. Producer Methods — @Produces, @Disposer, configuration
  6. Interceptors — @InterceptorBinding, @AroundInvoke, logging, security
  7. Transactions @Transactional — REQUIRED, REQUIRES_NEW, rollback strategies
  8. CDI Events — @Observes, @ObservesAsync, Event<T>, synchronous and asynchronous events

☰ Course Content

Scopes, @Inject, Qualifiers, Interceptors, Transactions and Events with diagrams.

◈ Key Concepts

CDI vs EJB, scope comparison, transaction types, CMT vs BMT, glossary.

⟨/⟩ Code Examples

@ApplicationScoped services, qualifiers, producers, interceptors, @Transactional, events.
